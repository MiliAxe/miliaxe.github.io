Personal blog of [Milad Zarei](https://miladzm.ir) (Mili), featuring thoughts, write-ups, and guides on low-level programming, GNU/Linux, networking, and software engineering.

The blog is live and accessible at:
- **Primary Domain:** [https://miladzm.ir](https://miladzm.ir)
- **GitHub Pages:** [https://miliaxe.github.io](https://miliaxe.github.io)

---

## Tech Stack

- **Framework:** [Astro](https://astro.build/)
- **Theme:** Based on [AstroPaper](https://github.com/satnaing/astro-paper)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Search:** [Pagefind](https://pagefind.app/)
- **Type Checking:** [TypeScript](https://www.typescriptlang.org/)

---

## Running Locally

Requirements: [Node.js](https://nodejs.org/) and [pnpm](https://pnpm.io/).

```bash
# Clone the repository
git clone https://github.com/MiliAxe/miliaxe.github.io.git
cd miliaxe.github.io

# Install dependencies
pnpm install

# Start the dev server (at http://localhost:4321)
pnpm dev

# Build for production
pnpm build

# Preview production build locally
pnpm preview
```
